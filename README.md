
# Interactive Calculator & Unit Converter

## Project Description
This project is a Python-based Interactive Calculator and Unit Converter. It performs basic arithmetic operations and converts different units.

## Features
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Kilometer to Miles Conversion
6. Celsius to Fahrenheit Conversion
7. Input Validation using While Loops
8. Error Handling for Invalid Inputs
9. Division by Zero Protection

## Technologies Used
- Python 3
- While Loops
- Conditional Statements
- Functions
- Exception Handling

## Unit Conversion Formulas

### Kilometer to Miles
Miles = Kilometer * 0.621371

### Celsius to Fahrenheit
Fahrenheit = (Celsius * 9/5) + 32

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python calculator.py

Enter first number: 10
Enter operator: +
